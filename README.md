# MediStudy — Demo Interaktif

Prototype website belajar untuk calon mahasiswa dan mahasiswa bidang kesehatan, dengan tampilan modern minimalis.

## Cara menjalankan
1. Ekstrak file ZIP.
2. Buka folder `medistudy-uiux`.
3. Buka `index.html` menggunakan Chrome, Edge, atau Firefox versi terbaru.
4. Masuk menggunakan nama panggilan; email bersifat opsional.

Tidak perlu instalasi, server, atau koneksi internet untuk menjalankan demo ini.

## Fitur yang dapat dicoba
- **Dashboard:** pintasan ke materi dan kalender.
- **Jelajah materi:** menampilkan semua materi, pencarian, dan filter bidang.
- **Lihat materi:** membuka pembaca materi, memilih modul, berpindah modul, serta menandai modul selesai.
- **Profil saya:** mengubah nama, email, status pendidikan, bidang minat, dan target belajar; mengunggah, mengganti, atau menghapus foto profil. Foto profil otomatis diperkecil dan disimpan di browser yang sama.
- **Catatan pribadi:** membuat, menyimpan, dan menghapus catatan.
- **Kalender:** berpindah bulan, menambahkan agenda, memilih tanggal, dan menghapus agenda.
- **Latihan soal:** memilih jawaban, memeriksa jawaban, membaca pembahasan, dan mengulang sesi.
- **Progres belajar:** melihat jumlah modul yang ditandai selesai, catatan, dan hasil kuis.

## Penyimpanan dan batasan
Data demo disimpan pada `localStorage` di browser/perangkat yang digunakan. Data tidak otomatis tersinkron ke perangkat lain. Login belum menggunakan autentikasi sungguhan dan belum ada backend/database. Materi serta soal adalah konten edukasi contoh, bukan kurikulum resmi atau panduan klinis. Jangan gunakan data demo sebagai pengganti sumber pendidikan kesehatan resmi.
